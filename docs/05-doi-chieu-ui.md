# 05 – Đối chiếu UI: Figma ↔ App (làm cuối kỳ)

**Cách làm**
1. Xuất từng frame Figma (PNG, 2x) vào `docs/design/figma/` đặt tên `S04_trang-chu.png`.
2. Chạy app trên emulator **cùng kích thước khung Figma** (ví dụ Pixel 7), chụp màn hình vào `docs/design/app/` cùng tên file.
3. Đặt hai ảnh cạnh nhau, điền bảng bên dưới. Chỗ nào lệch thì ghi nguyên nhân và cách xử lý.
